How to use the ratings

AI ratings are suggestions, not human expert judgments. Review the entire response, including the explanation and learning tip.

Correctness: 0 = materially incorrect diagnosis, false Java claim or harmful guidance. 1 = partially correct but incomplete or ambiguous. 2 = correct diagnosis and substantive advice.

Actionability: 0 = unhelpful or misleading. 1 = relevant but vague. 2 = a concrete useful next step.

Choose your own ratings, or use the AI scores after checking them. Save commits your review to a separate local file. Original results and AI ratings stay intact.

Valid alternative fixes need not match a private reference literal. A correct patch does not cancel a false Java rule elsewhere in the response.

Progression is about hint levels 1–3. A missing level can be N/A. Flag uncertain judgments for a second look.
